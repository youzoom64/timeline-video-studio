# 修正メモを編集へ対応づける例

コアウィーブ動画で指定された9項目の例。対象の理解に必要な素材と、その変化を決めるための参照であり、すべての動画に同じ順番や枚数を使うものではない。

| メモの対象 | 素材と配置 | 説明に沿う変化 |
| --- | --- | --- |
| AIサービスの役割 | 実際の利用画面と会社名、料金の図 | 依頼と回答から、利用者・提供会社・設備会社の支払いへつなぐ。 |
| 計算設備とは何か | GPU、サーバー、施設内部 | 部品の寄りから設備全体へ視野を広げる。 |
| 一回で終わる仕事 | メールの依頼と完成文 | 依頼を見せ、文章が返って仕事が終わるところを示す。 |
| 処理を繰り返す仕事 | コード、修正箇所、テスト結果 | 確認、修正、失敗、再修正、成功を発話に合わせて追う。 |
| 設備の事前準備 | 建設、設置、電力・冷却の実物 | 必要な準備を話す時刻に、その対象へ切り替える。 |
| 生産能力を予約する例 | 製造ライン、製品、予約生産枠 | 工場の実物から枠の図へつなぎ、注文が減っても最低料金が残る様子を示す。 |
| 既存設備と増設 | 稼働中と準備中の設備を対比 | 既存の運営・返済と、新しい設備への資金を区別して注目させる。 |
| 半導体と装置の仕事 | ウェハー、製造工程、検査装置 | 実物と工程を示してから、企業の製品と注文見通しの関係へつなぐ。 |
| 効率化の作用 | 同じ成果と、それに必要な処理量の比較 | 成果を固定して処理量を減らし、その後に費用・単価・利用増加への作用を示す。実測値と模式図を区別する。 |

各項目を未反映・一部反映・反映済みに分ける。単に画像が存在するだけでなく、求められた役割を実際の画面と発話の組み合わせで果たしているかを確認する。
