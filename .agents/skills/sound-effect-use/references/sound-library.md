# 音源DBを使う環境の確認

作業する作品の設定へ、音源DB、検索ツール、元音声フォルダーの場所を記録する。これらは利用者が用意するライブラリであり、エディタ本体のインストール先からは推測しない。

ベクトル検索では、DBの解析文と同じモデル・次元で検索文を埋め込む。モデル名と次元をDBのメタデータから読み、用途を表す検索文から候補を取り出す。

検索結果は候補ID、音の説明、長さ、近さ、元音声へのパスを返す。元音声の相対パスはライブラリの基準フォルダーから解決する。DBを移す場合は元音声との対応を維持する。

候補を実際に試聴して採否を決め、作品ごとの対応JSONへ音源のパス、配置対象のID、同期する変化、音量を保存する。配置の同期は同梱の `scripts/timeline_sfx_events.py` を使う。
